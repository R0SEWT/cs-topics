# Dataset Fotográfico (Físico)

Para cumplir estrictamente con la rúbrica del curso (1 punto por dataset de "condiciones variadas incluyendo versiones impresas"), deposite en este directorio al menos 10 imágenes reales de tableros KenKen tomadas con una cámara fotográfica.

## Instrucciones para los Estudiantes
1. Imprima 10 tableros KenKen.
2. Tome fotografías bajo distintas condiciones:
   - Luz de día / sombra / flash.
   - Rotación leve.
   - Curvatura del papel.
3. Guarde las imágenes aquí como `foto01.jpg`, `foto02.jpg`, ..., `foto10.jpg`.
4. Etiquete un archivo `ground_truth.json` si se desea medir la precisión contra estas fotos específicas o modifique `evaluar_real.py` para procesar esta carpeta.
